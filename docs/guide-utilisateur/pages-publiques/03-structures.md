# Structures

## Liste `/structures`

Liste des structures avec tutelles, identifiant ROR et lien vers la collection HAL. Une facette de type est réglée par défaut sur les laboratoires.

![Structures](../../img/screenshots/structures.png)

## Détails `/structures/{id}`

Onglets :

- **Dashboard** : chiffres clés (publications, part en open access, part de collaborations internationales, thèses, personnes présentes dans le SI RH), publications par année et par accès, sujets principaux, types de documents, pays partenaires ;
- **Publications** ;
- **Thèses** ;
- **Personnes** : les personnes liées à la structure par une publication, indépendamment de l'affiliation de la base RH ;
- **Collaborations** : [organisations partenaires](../../glossaire.md#organisation-partenaire), classées par nombre de copublications, filtrables par année, pays et type ; le nombre de copublications mène à la liste des publications concernées ;
- **Adresses** : adresses qui ont permis de détecter la structure dans les publications, en session d'administration ;
- **Gestion** : édition, tutelles, formes de nom, en session d'administration.

Le dashboard compte les publications de l'onglet Publications, restreintes à la famille « Publications » et aux années récentes. Les types de documents comptent toutes les familles, sur les mêmes années.
