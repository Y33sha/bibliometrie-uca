# Sujets

## Liste `/subjects`

Liste des sujets des publications, avec leur nombre de publications. La recherche interroge les libellés ; un nombre minimal d'occurrences écarte les sujets les moins employés. Export csv.

![Sujets](../../img/screenshots/subjects.png)

## Détails `/subjects/{id}`

Onglets :

- **Sujets associés** : graphe des sujets qui apparaissent avec celui-ci dans les mêmes publications ;
- **Publications**.
