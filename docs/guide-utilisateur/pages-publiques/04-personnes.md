# Chercheurs

## Liste `/persons`

Auteurs identifiés dans les publications de l'établissement, avec leurs identifiants de chercheur (ORCID, idHAL, IdRef). Une personne présente dans la [base RH](../../sources/10-imports-manuels.md#extraction-rh) affiche aussi son département et sa fonction.
